# The Forgotten Bond

## Overview
"The Forgotten Bond" is an action-platformer game currently in development. It features a unique blend of platforming mechanics, engaging combat, and a distinct artistic style, drawing inspiration from Japanese folklore (Yokai) and action-oriented gameplay.

## Project Structure
The project is built using Unity and organized as follows:
*   `Assets/Animations`: Contains animation controllers and clips for players, enemies, and UI elements.
*   `Assets/Audio`: Includes background music, sound effects, and dialogue audio.
*   `Assets/Ending`: Assets related to the game's ending sequence.
*   `Assets/Fonts`: Custom fonts used in the game's UI.
*   `Assets/Palletes`: Color palettes and environment prefabs (e.g., Forest, Cave).
*   `Assets/Scenes`: Unity scene files (e.g., MainMenu, StageOne, BossFight).
*   `Assets/Scripts`: C# scripts controlling game logic, player movement, enemy AI, UI, etc.
*   `Assets/Sprites`: 2D sprites for characters, items, tilemaps, and UI.

## Features
*   **Dynamic Combat**: Fast-paced combat system with various attack combos and defensive mechanics.
*   **Yokai Enemies**: Encounter diverse enemies inspired by Japanese mythology, each with unique behaviors and attack patterns.
*   **Engaging Platforming**: Navigate challenging environments with jump and dash mechanics.
*   **Interactive Environments**: Explore stages filled with hazards and interactable elements.
*   **Boss Fights**: Face challenging boss encounters that require strategic thinking and quick reflexes.
*   **Story-driven**: Uncover the narrative through cutscenes and dialogue sequences.

## Installation & Setup
1.  Clone the repository.
2.  Open the project in Unity.
3.  Open the `MainMenu` scene in `Assets/Scenes` to start the game.

## Scripts Overview
*   **Player Scripts**: Handle player movement, attacks, health, and interactions.
*   **Enemy Scripts**: Control enemy AI, movement, attacks, and health.
*   **Boss Scripts**: Manage complex boss behaviors and arena mechanics.
*   **UI Scripts**: Manage menus, health bars, and dialogue systems.
*   **Manager Scripts**: Handle scene transitions, checkpoints, and game state.
